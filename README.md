# FootCare — publicaciones

Instaladores de [FootCare](https://github.com/omarvazquezlopez3214/FootCareByIntegraphy),
la aplicación de valoración plantar y diseño de plantillas ortopédicas de Integraphy.

**Aquí no hay código.** Este repositorio existe solo para publicar los
instaladores, que es de donde la aplicación instalada se actualiza sola.

Cada publicación lleva dos archivos:

- FootCare-X.Y.Z-instalador.exe — el instalador
- FootCare-X.Y.Z-instalador.exe.sha256 — su huella, que la aplicación
  comprueba antes de ejecutar nada

## Para actualizar

No hace falta descargar nada a mano: en FootCare, **Ayuda → Buscar
actualizaciones**.
